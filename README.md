# MateriaX

MateriaX es una pagina web para un trabajo escolar sobre reutilizacion industrial y economia circular.

## Estructura

- `index.html`: pagina principal
- `css/styles.css`: estilos
- `js/main.js`: comportamiento interactivo
- `assets/`: imagenes, iconos, logos y fuentes
- `pages/`: futuras secciones o paginas internas

## Proximo paso

Este proyecto esta preparado para subirse a GitHub y compartirse con otras personas para trabajar en conjunto.
